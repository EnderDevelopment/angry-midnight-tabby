# Open Source SVG Illustration

Angry Midnight Tabby is an open source vector illustration project featuring a large black tabby cat with oversized angry eyes, visible fur stripes, an open mouth, sharp teeth, and stylized saliva. It is an editable SVG graphic suitable for digital artwork, posters, game assets, creative projects, and other vector illustration use cases.

## Install

1. Download or clone the project repository.
2. Locate `angry_tabby_cat.svg`.
3. Open the SVG in a modern web browser or an SVG-compatible editor such as Inkscape, Illustrator, or Affinity Designer.
4. Copy the file into your project assets directory if you are using it in a website or application.

No package manager, build process, or external dependency is required.

## Use

1. Open `angry_tabby_cat.svg` in an SVG-compatible application.
2. Edit the vector paths, colors, gradients, dimensions, or descriptive metadata as needed.
3. Use the SVG directly in a web page with an image element, as a CSS background, or in a graphics application.
4. Export it to another format such as PNG or PDF when required by your workflow.

The illustration uses a 1200 by 1000 view box and includes embedded gradients, shadows, and vector shapes. It does not load external images, fonts, scripts, or network resources.
